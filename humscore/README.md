# HumScore – Melody to Sheet Music PWA

Hum or sing a melody into your phone and instantly convert it into musical
notes, a staff preview, MIDI, and PDF – 100% in-browser, offline-capable.

---

## Quick Start

```bash
cd humscore
npm run setup          # install deps + generate icons
npm run dev            # start dev server at http://localhost:5173
```

## Production Build

```bash
npm run build          # TypeScript check + Vite build → dist/
npm run preview        # serve dist/ locally (HTTPS via browser-sync or ngrok)
```

## Local Development

1. **Install deps:** `npm install`
2. **Generate icons:** `node scripts/generate-icons.cjs`
3. **Dev server:** `npm run dev`
   - Open `http://localhost:5173` in Chrome/Safari
   - The service worker is enabled in dev mode (`devOptions.enabled: true`)

> **Note:** Microphone access requires HTTPS in production. For local dev,
> `localhost` is treated as a secure origin by all major browsers.

## Deploy Online

Any static host works. Recommended options:

| Platform | Command |
|----------|---------|
| **Vercel** | `vercel --prod` (from `humscore/`) |
| **Netlify** | drag-and-drop `dist/` in the dashboard |
| **GitHub Pages** | push `dist/` to `gh-pages` branch |
| **Cloudflare Pages** | connect repo, build command `npm run build`, output `dist` |

All deployments are automatically HTTPS, which is required for:
- Service worker registration
- MediaDevices / microphone API
- PWA installability

- ✅ `display: standalone`

- ✅ Mobile responsive

## iOS Safari Limitations

| Limitation | Mitigation |
|------------|-----------|
| No background audio processing | All analysis runs in foreground; stop recording before locking screen |
| MediaRecorder limited codec support | Falls back through `webm → ogg → mp4` |
| Web Audio `AudioContext` requires user gesture | Recording only starts after button tap |
| `prompt()` / `alert()` look native on iOS | Used sparingly (only in Settings/delete) |
| No Web MIDI API on iOS Safari | MIDI is exported as a file download, not played via Web MIDI |
| Service worker cache size varies | Workbox keeps asset cache lean; no audio blobs are precached |
| PWA cannot access Camera Roll or Files | Audio stays in IndexedDB or is downloaded |

### Installing on iPhone
1. Open the deployed URL in **Safari**.
2. Tap the **Share** button → **Add to Home Screen**.
3. The app opens full-screen with the indigo status bar.

## Connecting to PWA Builder for iOS Packaging

1. Get a passing score on [pwabuilder.com](https://www.pwabuilder.com).
2. Click **Package for Store → iOS**.
3. PWA Builder wraps the app in a WKWebView-based Xcode project.
4. Open the generated `.zip` in Xcode, add your Apple Developer Team ID.
5. Archive and submit to App Store Connect.

> Requires a paid **Apple Developer Program** membership ($99/year).

## Future AI Improvements

The current pitch detector (`src/utils/pitchDetection.ts`) uses a standard
autocorrelation algorithm, suitable for clean single-note humming. Here are
the natural upgrade paths:

### 1. CREPE (neural pitch estimator)
- Replace `detectPitch()` with the CREPE ONNX model (< 30 MB) via
  `onnxruntime-web`.
- Provides confidence scores and works on noisy audio.

### 2. Polyphonic transcription
- Libraries: **Basic Pitch** (Spotify, runs in-browser via TF.js), **Piano
  Transcription** (ISMIR 2020 model).
- Opens chord detection and multi-part music.

### 3. Rhythm & tempo tracking
- Add onset detection to infer note durations and barlines.
- Produce proper time-signature-aware sheet music.

### 4. VexFlow engraving
- Replace the hand-drawn SVG staff with VexFlow for standard-compliant
  music notation (ties, slurs, key/time signatures, multiple voices).

### 5. Online MIDI playback
- Use Tone.js `Sampler` with a General MIDI soundfont to play back detected
  notes in the app.

## Tech Stack

- **React 18** + **TypeScript**
- **Vite 5** + **vite-plugin-pwa** (Workbox GenerateSW)
- **Tailwind CSS v3** (mobile-first, dark theme)
- **Web Audio API** – `AnalyserNode` for real-time pitch analysis
- **MediaRecorder API** – audio capture
- **IndexedDB** (via `idb`) – local storage
- **jsPDF** – PDF export
- **Custom MIDI encoder** – pure TypeScript, no deps
